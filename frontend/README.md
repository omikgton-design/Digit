# Frontend (React + TypeScript)

## Run

1. Start Django backend (`http://127.0.0.1:8000`)
2. In this folder:

```bash
npm install
npm run dev
```

Vite dev server: `http://127.0.0.1:5173`

## REST API ашиглаж байгаа endpoint-ууд

- `GET /api/csrf/`
- `POST /api/auth/login/`
- `POST /api/auth/signup/`
- `POST /api/auth/logout/`
- `GET /api/auth/me/`
- `GET /api/profile/`
- `PUT /api/profile/`
- `GET /api/categories/`
